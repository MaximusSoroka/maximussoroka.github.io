Three free n8n templates

Small starting points you can import into your own n8n, test, and only then turn on. They are free. The JSON files contain no real passwords, keys or accounts — only placeholders you replace with your own.

In n8n, use … → Import from File and choose the workflow.json for the template you want. Follow the setup steps below. Leave the workflow inactive until a test run works.

RSS to daily digest email

Once a day (default 07:00 in the n8n instance timezone, set here to Europe/Lisbon), the workflow reads an RSS feed, builds an HTML list of up to 20 items, and emails the digest.

Download workflow.json

Setup

  1. In n8n: … → Import from File (or Add workflow → Import) and choose workflow.json.
  2. Open Read RSS feed and replace https://example.com/feed.xml with your feed URL. Use the same URL in the Code node if you want it printed in the email (feedUrl).
  3. In n8n, create an SMTP credential (your mailbox provider). Open Send digest email, remove the placeholder credential, and attach yours.
  4. Set From and To. Change the schedule in Every day at 07:00 if needed (the time follows the workflow timezone under Settings).
  5. Click Test workflow, confirm the email, then Activate. Leave it inactive until the test works.

Credentials in this file are placeholders: SMTP account (placeholder). Attach your own credentials in n8n before you activate the workflow.

Good to know

  • The Code node escapes titles and links before building HTML.
  • An empty feed still sends a short “no items” email so a silent failure is easier to notice.
  • Required n8n nodes are built-in: Schedule Trigger, RSS Read, Code, Send Email.

Form to Google Sheet and notification

An n8n form collects Name, Email and Message. Each submission is appended to a Google Sheet, then a notification email is sent.

Download workflow.json

Setup

  1. In Google Sheets, create a spreadsheet with a tab named Submissions.
  2. In row 1, add the headers exactly: submitted_at, name, email, message.
  3. Copy the spreadsheet ID from the URL (https://docs.google.com/spreadsheets/d/<ID>/edit).
  4. In n8n: … → Import from File and choose workflow.json.
  5. Open Append to Google Sheet, replace PLACEHOLDER_SPREADSHEET_ID with your ID, and attach a Google Sheets OAuth2 credential you created in n8n (the Google account must have access to the spreadsheet).
  6. Create an SMTP credential, attach it to Send notification email, and set From and To.
  7. Open Contact form, save the workflow, and copy the form URL n8n shows. Submit a test entry. Check the sheet and the inbox, then Activate.

Credentials in this file are placeholders: Google Sheets account (placeholder) and SMTP account (placeholder). Attach your own credentials in n8n before you activate the workflow.

Good to know

  • Form field labels (Name, Email, Message) must match the expressions in the Sheet and email nodes. Rename them in both places if you change the form.
  • The form path slug is contact-form (under the Form Trigger options). Change it if you already use that path.
  • Required n8n nodes are built-in: Form Trigger, Google Sheets, Send Email.

Website uptime check to alert

Every 5 minutes the workflow requests a URL. If the HTTP status is not 200, or no status is returned (timeout or network error), it waits 60 seconds and requests the URL again. An alert email is sent only if the second check also fails. A successful 200 on either check does not send mail.

Download workflow.json

Setup

  1. In n8n: … → Import from File and choose workflow.json.
  2. Open Request website and Retry request website and replace https://example.com/ with the URL to check in both nodes. Also replace that URL in the subject and body of Send down alert.
  3. Create an SMTP credential in n8n, attach it to Send down alert (remove the placeholder), and set From and To.
  4. The default retry wait is 60 seconds. To change it, open the Wait 60 seconds node and edit Amount and Unit.
  5. Optionally change the interval in Every 5 minutes, the 10-second timeout, or the If conditions if you want to accept other 2xx codes.
  6. Run a test against a URL you control (or temporarily point it at a path that returns 404) to see the wait and the alert, then point it at the real URL and Activate.

Credentials in this file are placeholders: SMTP account (placeholder). Attach your own credentials in n8n before you activate the workflow.

Good to know

  • After the first failed check, the workflow waits 60 seconds and requests the URL again. The alert is sent only if that second check also fails (status other than 200, or a missing status).
  • The HTTP nodes use “full response”, “never error”, and onError: continueRegularOutput, so a 4xx/5xx or a failed request can be evaluated instead of stopping the workflow.
  • This is a simple local check, not a hosted monitoring service. It will not run while n8n is stopped, and it does not measure uptime percentages.
  • Required n8n nodes are built-in: Schedule Trigger, HTTP Request, If, Wait, Send Email.

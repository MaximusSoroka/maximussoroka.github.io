Why we recommend n8n — honestly, with sources

This article is an honest, sourced recommendation of n8n. There are no active affiliate links on this site at the moment; product buttons go to the official vendor pages. This page may contain affiliate links in the future; those will be labelled #ad / Anzeige. There is no earnings promise and no revenue of our own (so far €0). Not financial advice, not a trading product.

It is about tools that connect recurring workflows between apps, or that build agent workflows.

The recommendation in one sentence

For most cases that matter in this project — being able to self-host, choosing where data lives, and paying for complete workflow runs rather than every step — we recommend n8n. Make remains a serious alternative if you want to start without your own server and prefer a credits model with a free plan. A blanket claim that “n8n is always cheaper” is not substantiated.

Why n8n

  • Pricing model: In the cloud, n8n bills by monthly workflow executions, regardless of complexity. A run counts as one execution even if the workflow has many steps. According to the pricing page (billed annually): Starter €20/month, Pro €50/month, Business €667/month, Enterprise on request. All plans include, according to the vendor, unlimited users, workflows and integrations. Monthly billing exists according to the documentation and is more expensive; the monthly amounts were not stated as figures on the public pricing page, so they are not stated here either.
  • Self-hosting: The Community Edition for self-hosting is free on GitHub. Paid Business/Enterprise options also exist with self-hosting. If you run the server yourself, you decide where the data lives.
  • Cloud data location: For hosted cloud plans, n8n names Frankfurt (EU) as the storage location.
  • Trial: 14 days, according to n8n, without a credit card on the pricing page.

That fits the typical decision in this project better than a purely hosted credits model.

Where Make can honestly be a better fit

Make is a hosted, visual platform and bills in credits per action. Most actions use 1 credit, some AI features use more. Unused credits expire at the end of the period. If you run out of credits, scenarios stop until credits are available again.

On the free plan, Make states 1,000 credits per month. Prices for paid plans were not reliably readable when the official pricing page was retrieved; they are therefore not listed here.

If you want to start quickly without your own server and need a free entry allowance, Make can be the more practical first step. Whether Make or n8n is cheaper for the same flow depends on how many steps a flow has and how often it runs. That cannot be predicted in euros in general.

What this recommendation is not

  • Not evidence that an affiliate link or a subscription will pay off for you.
  • Not “always n8n, never Make”.
  • Not a comparison of the user interface as a taste judgement without a source.

A practical start (no account is created for you here)

  1. Write down your own flow in steps (trigger, how often, which apps, whether data should stay in the EU).
  2. Think through the same flow once as an n8n execution and once as a Make credit chain.
  3. Check the current official pricing pages; figures in this article apply to 18 November 2026 and can change.
  4. Only then create an account — that is your decision, not part of this article. If you follow our recommendation, start with n8n (cloud or Community Edition).
